# Raport Utilizare Asistență AI - Tehnologii Web (Laboratoarele 1 & 2)

## 1. Laboratorul 1: HTML, CSS și Structura paginii (City Explorer)
* **Obiectiv:** Crearea machetei statice a paginii web pentru proiectul *City Explorer* folosind elemente semantice HTML și stilizare CSS.
* **Contribuția AI-ului:**
  * Asistență în structurarea corectă a elementelor semantice (`header`, `main`, `section`, `footer`).
  * Recomandări pentru stilizarea responsive folosind Flexbox/Grid.
  * Suport în identificarea și corectarea erorilor minore de sintaxă CSS/HTML.

## 2. Laboratorul 2: Vite și JavaScript modern (City Explorer)
* **Obiectiv:** Migrarea proiectului pe mediul Vite, utilizarea modulelor ES, implementarea metodelor pe liste (`map`, `filter`, `reduce`), asigurarea imutabilității datelor și preluarea de date de la un server extern (`fetch`, `async/await`, `try/catch`).
* **Contribuția AI-ului:**
  * Îndrumare pas cu pas pentru configurarea inițială a proiectului în Vite + React și organizarea directoarelor (`src/data`, `src/utils`, `src/api`).
  * Explicații conceptuale și implementarea practică a funcțiilor de prelucrare a listelor (în special funcția `reduce` pentru agregări și grupări pe țări).
  * Ghidaj privind păstrarea imutabilității datelor originale prin utilizarea operatorului `spread` (`...`) și crearea de noi instanțe.
  * Suport în scrierea cererilor asincrone și gestionarea corectă a erorilor HTTP (verificarea `response.ok` și utilizarea blocurilor `try/catch`).
  * Depanarea erorilor din consola browserului și rezolvarea problemelor de sintaxă sau de import/export a modulelor.
